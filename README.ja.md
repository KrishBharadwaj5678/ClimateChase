<h1 align="center">🌦️ Climate Chase</h1>

<p align="center">
  Climate Chaseは、リアルタイムの天気情報と正確な天気予報を提供する天気アプリケーションです。最新の天気情報を簡単に確認でき、ユーザーが一日の予定を立てるのに役立ちます。
</p>

![ClimateChaseDemo](https://github.com/KrishBharadwaj5678/ClimateChase/raw/main/demos/ClimateChaseDemo.png)

<img src="https://github.com/KrishBharadwaj5678/ClimateChase/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/ClimateChase/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能                   | 説明                           |
| -------------------- | ---------------------------- |
| ⛅ **世界中の天気情報**       | 世界中の都市の天気状況を確認できます           |
| 🌡️ **リアルタイムの天気データ** | 現在の気温、湿度、天気の状況をリアルタイムで取得できます |
| 🔎 **都市のクイック検索**     | 都市名を入力するだけで天気情報を検索できます       |
| 💻 **クロスプラットフォーム対応** | どのブラウザやデバイスからでも天気サービスを利用できます |

## <img src="https://github.com/KrishBharadwaj5678/ClimateChase/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/ClimateChase.git
```

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd ClimateChase
```

### 3️⃣ ブラウザで開く

`index.html` をブラウザで開くだけで使用できます。
