<h1 align="center">🌦️ Climate Chase</h1>

<p align="center">
  Climate Chase это приложение для просмотра погоды, предоставляющее обновления в реальном времени и точные прогнозы. Оно позволяет получать актуальную информацию о погоде и помогает пользователям планировать свой день.
</p>

## <img src="https://github.com/KrishBharadwaj5678/ClimateChase/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность                                | Описание                                                    |
| ------------------------------------------ | ----------------------------------------------------------- |
| ⛅ **Погода по всему миру**                 | Проверяйте погодные условия в городах по всему миру         |
| 🌡️ **Данные о погоде в реальном времени** | Получайте текущую температуру, влажность и погодные условия |
| 🔎 **Быстрый поиск города**                | Находите информацию о погоде, просто введя название города  |
| 💻 **Кроссплатформенный доступ**           | Используйте сервис погоды на любом браузере или устройстве  |
