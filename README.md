<h1 align="center">🌦️ Climate Chase</h1>

<p align="center">
 Climate Chase is a weather application that provides real-time weather updates and accurate forecasts. It gives users upto date weather information, helping them to plan their day accordingly.
</p>

![ClimateChaseDemo](https://github.com/KrishBharadwaj5678/ClimateChase/raw/main/demos/ClimateChaseDemo.png)

<img src="https://github.com/KrishBharadwaj5678/ClimateChase/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/ClimateChase/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature                      | Description                                               |
| ---------------------------- | --------------------------------------------------------- |
| ⛅ **Worldwide Weather**     | Check weather conditions for cities around the globe      |
| 🌡️ **Live Weather Data**    | Get current temperature, humidity, and weather conditions |
| 🔎 **Quick City Search**     | Find weather information by simply entering a city name   |
| 💻 **Cross-Platform Access** | Use the weather service on any browser or device          |
